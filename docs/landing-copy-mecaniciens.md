## Section FAQ

**Q : Mes clients doivent-ils créer un compte ?**  
R : Non. Ils décrivent leur problème, uploadent des photos, choisissent un créneau. C'est tout.

**Q : Comment je fais un devis sans voir le véhicule ?**  
R : Les photos + description vous donnent une estimation. Le devis final se fait à l'arrivée, mais le client a déjà une idée du budget.

**Q : Puis-je personnaliser les types de RDV ?**  
R : Oui. Diagnostic, entretien, réparation, pneus, contrôle technique... Vous définissez vos prestations et durées.

**Q : Et si le client ne se présente pas ?**  
R : Vous recevez son email et téléphone. Vous pouvez le relancer. Les SMS de rappel (version Pro) réduisent les no-shows.
